# F-01 회원가입 · 로그인 (Supabase) 연동 가이드

> 2026-10-12 실제 기기(Galaxy SM-S947N)에서 학교 메일 코드 인증 → 프로필 저장까지 확인 완료.

## 가입 흐름

| 단계 | 화면 | Supabase 호출 |
|---|---|---|
| 1 | 학교 이메일 입력 (`학번@a.ut.ac.kr`) | `auth.signInWithOtp` → 6자리 코드 메일 발송 (처음이면 계정 생성) |
| 2 | 6자리 코드 입력 (10분 타이머, 20초 후 재발송) | `auth.verifyOTP(type: email)` → 로그인 세션 생성 |
| 3 | 닉네임 · 비밀번호 · 약관 | `auth.updateUser(password)` → RPC `f01_complete_signup` |
| 로그인 | 이메일 + 비밀번호 | `auth.signInWithPassword` |
| 비밀번호 찾기 | 코드 + 새 비밀번호 | `resetPasswordForEmail` → `verifyOTP(type: recovery)` → `updateUser` |

- 2단계에서 코드를 확인하는 순간 로그인 상태가 되므로, 3단계를 끝내지 않은 사용자는
  `SignupCompletionGate` 가 붙잡아 3단계 화면을 보여 준다.
- 1단계에서 뒤로 갔다가 20초 안에 다시 요청하면, 오류 대신 방금 보낸 코드를 입력하는 화면으로 이동한다.
- 허용 도메인: `a.ut.ac.kr`(재학생), `ut.ac.kr`(교직원). 그 외 메일은 서버 트리거가 가입을 막는다.

## 1. Supabase 대시보드 설정 (코드로 전달되지 않으니 직접 설정)

### Authentication → Sign In / Providers → Email
| 항목 | 값 | 비고 |
|---|---|---|
| Enable email provider | 켜기 | |
| Confirm email | 켜기 | |
| **Email OTP Length** | **`6`** | ⚠️ 새 프로젝트 기본값이 **8** 이라 꼭 바꿔야 함 (안 바꾸면 인증 실패) |
| Email OTP Expiration | `600` | 10분 (회의록 F-01) |
| Minimum password length | `8` | |
| Secure password change | 끄기(기본값) | 켜면 3단계 비밀번호 설정이 막힘 |

### Authentication → Emails → SMTP Settings (필수)
무료 요금제는 **커스텀 SMTP 를 연결해야 메일 템플릿을 수정할 수 있다.**
(기본 메일 서버는 링크 방식 고정 + 시간당 2~4통 제한)

| 항목 | 값 |
|---|---|
| Sender email / Username | 발송용 Gmail 주소 |
| Sender name | `같이타` |
| Host | `smtp.gmail.com` |
| Port | `465` |
| Minimum interval per user | `20` (앱의 재발송 대기 시간과 같게) |
| Password | Gmail **앱 비밀번호** (Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호) |

- 앱 비밀번호는 **절대 코드·채팅·문서에 적지 말 것.** 대시보드 입력칸에만 붙여 넣는다.
- 연결하면 시간당 발송 한도가 30통으로 올라간다.
- Gmail 에서 학교 메일로 보낸 메일은 스팸함에 들어갈 수 있다.

## 2. DB 설정

F-01 SQL은 팀 방식대로 마이그레이션 파일 `supabase/migrations/202610110000_f01_signup.sql` 로 들어 있다.
팀 README 1.3의 `supabase db push` 를 실행하면 공통 기반 → F-07·F-08·F-10 → **F-01** 순서로 함께 적용된다.
(CLI 대신 SQL Editor 에 파일 내용을 순서대로 붙여 넣고 Run 해도 된다. F-01 은 공통 기반만 있으면 동작한다.)

- 학교 메일(`a.ut.ac.kr`, `ut.ac.kr`)이 아니면 가입 자체를 막는 트리거
- 닉네임은 팀 구조대로 `profiles.display_name` 에 저장 + 대소문자 무시 중복 금지 인덱스
  (이미 profiles 에 같은 display_name 이 여러 개 있으면 인덱스 생성이 실패하므로 먼저 정리)
- `profiles` 에 `terms_version`, `terms_agreed_at` 컬럼 추가
- 가입하면 `profiles` 행이 자동으로 생기므로, 팀 README 1.4의 "SQL로 프로필 수동 등록"이 필요 없어짐
- RPC 3개: `f01_nickname_available`, `f01_signup_completed`, `f01_complete_signup` (로그인한 사용자만 호출 가능)

가입 확인용 쿼리:
```sql
select u.email, u.email_confirmed_at is not null as confirmed, p.display_name, p.terms_agreed_at
from auth.users u left join public.profiles p on p.id = u.id
order by u.created_at desc;
```

## 3. 팀 공유본에 합치기

1. `lib/features/auth/` 폴더를 팀 공유본의 같은 위치로 복사한다. (다른 패키지 추가 없음, `supabase_flutter` 만 사용)
2. `lib/main.dart` 의 `teamFeatures` 에 가입 화면을 연결한다.
   ```dart
   import 'features/auth/signup_flow.dart';

   const teamFeatures = TeamFeatureBindings(
     authenticationBuilder: _signup,
   );
   Widget _signup(BuildContext context) => const SignupFlow();
   ```
   `TeamFeatureBindings` 가 const 라서 최상위 함수로 넘긴다.
3. `lib/core/session_gate.dart` 의 로그인된 쪽을 `SignupCompletionGate` 로 감싼다.
   ```dart
   import '../features/auth/signup_flow.dart';
   ...
   return KeyedSubtree(
     key: ValueKey(user.id),
     child: SignupCompletionGate(
       child: builder(SupabaseCompanionRepository(Supabase.instance.client)),
     ),
   );
   ```
   이걸 빼면 2단계 직후 3단계를 건너뛰고 앱으로 들어가 버린다.
4. `android/app/src/main/AndroidManifest.xml` 에 인터넷 권한이 있는지 확인한다.
   Flutter 기본 템플릿은 debug 에만 넣어 두기 때문에, 없으면 **릴리스 빌드에서 "서버에 연결하지 못했어요"** 가 뜬다.
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   ```

## 4. 단독 실행 (이 프로젝트)

```powershell
Copy-Item config/development.example.json config/development.json   # 처음 한 번
# development.json 에 SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY 입력 (Supabase → Settings → API Keys)
flutter run --dart-define-from-file=config/development.json
```

- 실제 폰 테스트 권장: 폰에서 개발자 옵션 → USB 디버깅 켜고 USB 연결.
  갤럭시는 **설정 → 보안 및 개인정보 보호 → 자동 차단** 이 켜져 있으면 USB 디버깅이 막힌다.
- 디버그 빌드는 느리다. 체감 속도 확인은 `flutter build apk --release --dart-define-from-file=config/development.json` 로.
- Windows 에서는 Flutter SDK·프로젝트·Android SDK 경로에 **한글이 없어야** 빌드가 된다.
